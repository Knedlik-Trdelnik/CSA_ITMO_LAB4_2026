# Описание языка

Синтаксис в ~~расширенной~~ нагло присвоенной БНФ.

- `[ ... ]` -- вхождение 0 или 1 раз
- `{ ... }` -- повторение 0 или несколько раз
- `{ ... }+` -- повторение 1 или несколько раз
``` help me...
<программа> ::= <точка входа в программу> {<фукция>}
<точка входа в программу> main <секция программы> main-end
<секция программы> ::= {<коли-loop>|<пока-loop>|<присваивание>|<переменная>} ;

<ключевые слова> ::= goto,main,main-end, call
<метка> ::= ::<строка>::
<фукция> ::= function <строка>({<переменная>}+) end
<коли-loop> ::= for (условие) [<мат выражение>|<переменная>] for-end
<пока-loop> ::= while (условие) [<мат выражение>|<переменная>] while-end

<условие> ::= <мат выражение>|<переменная> <операция сравнения> <мат выражение>|<переменная>
<операция сравнения> ::= "=" | "<" | ">"

<присваивание> ::= <строка> = <number> | <строка> | <мат выражение>
<переменная> ::= <тип переменной> <строка> = [<число> | <строка> | <мат выражение>]
<тип переменной> ::= цело|долгоцело|грамота
<мат выражение> ::= [<мат операция>]{<число> [<мат операция> <число>]}+
<мат операция> ::= +|-|%|:|*
<число> ::= [-2^31; 2^31 - 1]
<строка> ::= {буква}+
<буква> ::= [a-z] | [A-Z]
<комментарий> ::= ";" <любые символы кроме "\n">
```

Примеры программ: 
``` help me...
main;
цело a = 15;
a = a + 1;
print(a);
main-end;
---------
Вывод : 16
```

for-end

main-end;

```

```
