Язык программирования

Синтаксис языка алгоритмический (C/Java-подобный), адаптированный для трансляции
в стековую архитектуру. Язык строго последовательный, поддерживает глобальные
переменные, математические выражения, циклы и ветвления.

Синтаксис (BNF)

<программа> ::= [ <обработчик прерывания> ] <точка входа в программу>

<обработчик прерывания> ::= "trap" <имя_обработчика> ";" <секция программы> "trap-end" ";"
<точка входа в программу> ::= "main" ";" <секция программы> "main-end" ";"

<секция программы> ::= { <объявление_переменной> | <присваивание> | <условие> | <цикл> | <ввод_вывод> | <управление_прерываниями> }

<объявление_переменной> ::= <тип_переменной> <имя> "=" <выражение> ";"
<присваивание> ::= <имя> "=" <выражение> ";"

<условие> ::= "if" "(" <логическое_выражение> ")" ";" <секция программы> "if-end" ";"
<цикл> ::= "while" "(" <логическое_выражение> ")" ";" <секция программы> "while-end" ";"
         | "for" "(" <объявление_переменной> "," <логическое_выражение> "," <присваивание> ")" ";" <секция программы> "for-end" ";"

<ввод_вывод> ::= "пиши_память" "(" <выражение> ")" ";"
               | "пиши_строку" "(" <выражение> ")" ";"
               | "читай_память()"
               | "читай_адрес" "(" <имя> ")"
               | "пиши_адрес" "(" <имя> "," <выражение> ")" ";"

<управление_прерываниями> ::= "ei" ";" | "di" ";"

<логическое_выражение> ::= <выражение> <операция_сравнения> <выражение>
<операция_сравнения> ::= "==" | "<" | ">"

<выражение> ::= <терм> { <мат_операция> <терм> }
<терм> ::= <число> | <имя> | <строковый_литерал> | "читай_память()" | "читай_адрес(" <имя> ")"
<мат_операция> ::= "+" | "-" | "*" | ":" | "%" | "&"

<тип_переменной> ::= "цело" | "долгоцело" | "грамота"
<число> ::= [-2^31; 2^31 - 1]
<строковый_литерал> ::= '"' { <любой_символ> } '"'

Семантика

  - Глобальная область видимости: Все переменные статически размещаются в Data
    Memory при компиляции.
  - Типы данных: Машинное слово процессора — 32 бита (знаковое). Строки (cstr)
    хранятся в памяти данных как нуль-терминированные массивы символов (один
    символ = одно машинное слово).
  - Выражения: Инфиксные математические выражения автоматически транслируются
    компилятором в постфиксную запись (Обратную польскую нотацию) для
    исполнения на стековой машине.
  - Указатели: Поддерживается косвенная адресация через читай_адрес и пиши_адрес
    для работы со строками как с массивами.

Организация памяти

Архитектура Гарвардская (harv). Память команд (Instruction Memory) и память
данных (Data Memory) физически и логически разделены.

Память данных (Data Memory)

Размер ячейки: 32 бита. Адресация: линейная, абсолютная.

  - 0x0000 — Зарезервировано. Хранит вектор прерывания (адрес начала trap).
  - 0x0001 ... 0x7CFD — Глобальные переменные и статические строки.
  - 0x7CFE (31998) — Порт ввода (INPUT_PORT_ADDR).
  - 0x7CFF (31999) — Порт вывода (OUTPUT_PORT_ADDR).

Аппаратные стеки (stack)

Стеки вынесены в отдельные аппаратные блоки RAM фиксированного размера (по 256
слов). Не имеют адресации из основной памяти, управляются внутренними
счётчиками stack_pointer.

  - Data Stack (DS): Хранит операнды для АЛУ.
  - Return Stack (RS): Хранит адреса возврата (PC) и регистр состояний (SR) при
    прерываниях и вызовах функций.

Система команд и АЛУ

Устройство управления — Hardwired (hw). Процессор моделируется с точностью до
такта (tick).

Кодирование инструкций (binary)

Инструкции кодируются бинарно (Big-Endian).

  - Инструкция без аргумента: 1 байт (опкод).
  - Инструкция с аргументом: 5 байт (1 байт опкод + 4 байта аргумент).

Набор команд (ISA)

| Опкод  | Мнемоника | Арг?    | Такты | Описание                                       |
| ------ | --------- | ------- | ----- | ---------------------------------------------- |
| `0x00` | `INC`     | Нет     | 2     | Увеличить вершину стека на 1                   |
| `0x03` | `ADD`     | Нет     | 2     | Сложить два верхних значения `DS`              |
| `0x02` | `SUB`     | Нет     | 2     | Вычесть верхнее из второго значения `DS`       |
| `0x04` | `MUL`     | Нет     | 2     | Умножить два верхних значения                  |
| `0x05` | `DIV`     | Нет     | 2     | Целочисленное деление                          |
| `0x26` | `MOD`     | Нет     | 2     | Взятие остатка от деления                      |
| `0x13` | `AND`     | Нет     | 2     | Побитовое И                                    |
| `0x06` | `LIT`     | Да (4b) | 1     | Загрузить константу на вершину `DS`            |
| `0x0F` | `LOAD`    | Да (4b) | 2     | Загрузить значение из памяти в `DS`            |
| `0x1F` | `STORE`   | Да (4b) | 2     | Записать значение с `DS` в память              |
| `0x0E` | `ALOAD`   | Нет     | 2     | Косвенное чтение из памяти по адресу в `Reg A` |
| `0x25` | `NIF`     | Да (4b) | 2     | Переход (Jump if Not Zero)                     |
| `0x23` | `EI`      | Нет     | 1     | Разрешить прерывания                           |
| `0x24` | `DI`      | Нет     | 1     | Запретить прерывания                           |
| `0x22` | `IRET`    | Нет     | 2     | Возврат из прерывания                          |
| `0xFF` | `HALT`    | Нет     | 1     | Остановка симуляции                            |

АЛУ обновляет однобитные защёлки флагов N (Negative) и Z (Zero) на каждой
арифметической операции. Флаги объединены в виртуальный регистр SR.

Ввод-вывод и система прерываний (Trap)

Система работает на базе внутренних аппаратных прерываний (trap) и Memory-Mapped
I/O (mem).

1.  Ввод по таймеру: Внешнее устройство (файл расписания) выставляет ASCII-код
    символа в порт 31998 в заданный такт и поднимает аппаратный флаг
    pending_interrupt. Очередей ввода нет (принцип реализма: не успел прочитать
    — данные затёрты новым символом).
2.  Аппаратный вход (5 тактов): Если прерывания разрешены (EI), ControlUnit
    аппаратно перехватывает управление:
      - T1: Сохранение PC в Return Stack.
      - T2: Сохранение SR (флагов N, Z) в Return Stack.
      - T3: Установка Address Register в 0.
      - T4: Загрузка вектора прерывания из DataMemory[0] на Data Stack.
      - T5: Перенос вектора со стека в PC. Переход к обработчику.
3.  Возврат: Инструкция IRET восстанавливает флаги SR и адрес PC из Return
    Stack.

Векторное расширение (Vector)

Архитектурное проектирование для усложнения vector. Для поддержки векторизации в
стековую архитектуру внедряется параллельный тракт:

  - Vector Stack (VS): Аппаратный стек, где каждый элемент является массивом
    из 4-х 32-битных слов (128 бит).
  - Vector ALU: Параллельно выполняет 4 операции (VADD, VSUB, VMUL) за один
    такт.
  - Инструкции VLOAD/VSTORE: За один цикл обращения к памяти читают/пишут 4
    последовательных адреса, реализуя концепцию SIMD.

Транслятор

  - Модуль: translator.py
  - Транслятор работает по принципу прямого прохода. Математические инфиксные
    операции преобразуются в AST (Абстрактное Синтаксическое Дерево) и
    обходятся в глубину для генерации постфиксного байт-кода.
  - Ветвления и циклы решаются через временные заглушки (<if-end-ID>), которые
    "патчатся" (patching) абсолютными адресами памяти команд после завершения
    компиляции блока.
  - Вывод компилятора включает человекочитаемое Абстрактное Синтаксическое
    Дерево (AST) для отладки.

Модель процессора

  - Модуль: machine.py
  - Класс DataPath содержит аппаратную реализацию памяти, регистров A/B (в
    качестве буферов адресации), АЛУ и стеков (через массивы
    фиксированного размера с stack_pointer).
  - Класс ControlUnit реализует потактовое (tick) выполнение (микрошаги
    self.step). Моделирование приостанавливается на каждом такте для
    логирования.

Тестирование

Тестирование (golden tests) реализовано с помощью фреймворка pytest. Формат
тестов .yml включает в себя исходный код, ввод, и полный детальный лог
работы: AST, байт-код, журнал потактового моделирования и дамп памяти.
Вывод ограничен до 100 тактов для репрезентативности.

Для запуска тестов:

pytest tests/test_integration.py -v

Алгоритмы:

1.  hello_world: Простой вывод строки. Использует DI (запрет прерываний).
2.  cat: Чтение данных через порт ввода в прерывании по таймеру и мгновенный
    вывод.
3.  hello_user: Интерактивный запрос имени. Процессор крутится в пустом цикле
    while, пока trap принимает посимвольный ввод по расписанию, и добавляет имя
    к приветствию.
4.  sort: Сортировка массива (строки как C-string) алгоритмом "Пузырёк".
    Использует косвенную адресацию (указатели читай_адрес, пиши_адрес).
5.  math64: Арифметика двойной точности. Эмуляция 64-битного сложения с
    проверкой бита переноса (через оценку переполнения 32-битного
    знакового int и побитовый AND).
6.  prob1 (Euler 4 - Палиндром): Поиск самого большого палиндрома, полученного
    умножением двух трехзначных чисел (999 * 999). Интенсивная математическая
    задача, решаемая за миллионы тактов с максимальной алгоритмической
    оптимизацией.

CI (Continuous Integration)

Настроен в файле .github/workflows/python-app.yml. Выполняет суровые проверки
кода с помощью ruff (линтер и автоформаттер), mypy (строгая проверка типов
Python) и автоматически запускает pytest.

# Пример запуска CI из консоли
ruff check .
ruff format --check .
mypy .
pytest tests/test_integration.py
